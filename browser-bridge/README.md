# AutoFish 闲鱼商家工作台浏览器桥接

这是 AutoFish 的本地 Chrome 执行代理。它通过独立令牌从 NAS 领取固定类型任务，复用浏览器中已登录的 `seller.goofish.com` 会话。

`0.4.0` 新增只读商品日报采集：自动打开「商品数据」，固定读取「近1天」T+1 指标并逐页写入 AutoFish 流量诊断。该能力不会修改商品，也不会读取 Cookie 或买家隐私。

`0.4.1` 修复闲鱼商品数据分页可能返回重叠行的问题：相同商品且指标完全一致时安全去重并记录跳过数量；同一商品指标不一致时仍立即停止，避免写入不确定数据。分页切换改用整页商品 ID 指纹和稳定等待，防止读取过渡态。

`0.4.2` 在商品数据采集前自动选择闲鱼工作台允许的最大分页容量（不超过 500 条），优先将日报收敛为单页；分页仍存在时继续执行整页指纹、稳定等待和逐商品一致性校验。

安全边界：

- 不读取、导出或上传 Cookie、Token、密码和浏览器存储。
- 不接受任意 JavaScript、CSS 选择器或目标 URL。
- 仅当 NAS 硬开关与 GLOBAL/PUBLISH 自动化策略同时放行时，执行固定的商品发布动作；仍不执行发货、退款、取消、删除、支付或充值。
- 遇到验证码、滑块、安全验证或页面结构不匹配时立即转人工。
- 发布图片必须来自 AutoFish 自主流水线、通过视觉事实质检并通过下载前后 SHA-256 校验。
- 最终提交前会再次回读文案、价格和图片状态；提交开始后如果结果不明确，不会自动重试。
- 商品发布菜单被页面浮层遮挡时，只使用固定的同源商品发布 hash 路由，不执行任意 URL 跳转。
- 最终按钮只通过 `chrome.debugger` 的 `Input.dispatchMouseEvent` 发送一次真实鼠标点击；坐标必须由已校验的可见“发布”按钮生成且位于当前视口，扩展随即脱离调试通道。该权限不用于执行脚本、读取 Cookie、抓取网络响应或点击其他按钮。
- 只向 NAS 回传模块列表、结构化商品经营指标、字段填写结果、发布成功证据和安全状态，不回传完整页面文本、Cookie 或截图。

安装：

1. Chrome 打开 `chrome://extensions`，启用“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本目录 `browser-bridge/`。
3. 在扩展设置中填写 AutoFish API 地址和 `xianyu-browser-bridge-token` 文件中的令牌。
4. 在 AutoFish 中启用 GLOBAL 与 PUBLISH 控制，并把 PUBLISH 设为 `AUTOMATIC`；需要无人值守最终提交时，再在 NAS `.env` 开启 `AUTOFISH_XIANYU_BROWSER_PUBLISH_ENABLED=true`。
5. 保持闲鱼商家工作台登录；扩展每 30 秒领取一次任务，也可在弹窗中立即领取。

0.5.1 首次加载或从旧版本升级时，Chrome 会提示扩展获得调试器权限。该权限用于让闲鱼接收到可信的单次发布点击；未授予时系统会在提交前失败，不会回退到非可信 DOM 点击。

发布前可在项目根目录执行 `node scripts/check_browser_bridge.mjs`，核对扩展版本、权限、消息协议，以及调试通道只使用 `Input.dispatchMouseEvent` 的静态安全契约。

首次验证顺序：先执行“检测工作台”，再执行模块跳转和单个草稿预填，最后通过 AutoFish 页面创建一条明确确认的发布任务。单款验收通过后再启用自动发布硬开关。
