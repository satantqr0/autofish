# AutoFish 0.4.0 对抗性测试报告

测试日期：2026-08-16  
测试范围：闲鱼人工网页快照、账号隔离、鉴权边界、事实/动作幂等、自动化策略、适配器故障、客服风险分流、事件 webhook、前端交互和 NAS 运行态。

## 威胁模型

系统只接收本人账号的规范化事实或经授权 Adapter/Gateway 事件，不接收浏览器 Cookie、验证码、设备指纹或反检测参数。外部写动作只能通过统一状态机执行；采购/支付、退款/投诉、赔偿、法律问题和平台介入不能无人值守执行。

## 测试中发现并修复的问题

1. 手工快照时间曾以 Python `datetime` 直接进入 JSON 列，SQLite/PostgreSQL JSON 序列化不一致；现统一为带时区 ISO 8601 字符串。
2. 会话同步曾先检查 Adapter 开关，再检查资源所有权，可被用于探测运行状态；现先进行对象级授权，越权统一返回 404。
3. ORM 模型的 `product_id` 可空声明曾与 Phase 3/4 数据库迁移不一致；现已统一，外部商品事实无需伪造内部商品。
4. 完整快照重导时，消失商品可能继续显示为在售；现将其标记为 `REMOVED` 并保留事实链。

## 仍然保留的安全边界

- 闲鱼官方 Adapter 仍为 `AUTH_REQUIRED` 时，不允许自动读取会话和订单。
- NAS 当前所有平台写能力和自动调度仍保持关闭；本报告证明安全状态机可用，不等于平台授权或无人值守获准上线。
- 局域网 HTTP 入口不得直接暴露到公网；公网化前必须增加 HTTPS、访问控制和独立渗透测试。
- 1688 社区技能在依赖、许可证、网络目标和埋点审计完成前保持未安装、未启用。
