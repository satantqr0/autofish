# AutoFish 自主上架产品化验收记录

验收日期：2026-08-17  
部署目标：铁威马 NAS（AutoFish Web `18180`、API `18181`）  
验收结论：自主生成链路可用，停在浏览器交接点；未执行闲鱼最终提交。

## 职责边界

当前系统不是由 Codex 代替 AutoFish 做选品和内容生产。职责已经调整为：

| 环节 | 执行者 | 结果 |
| --- | --- | --- |
| 候选选择、SKU 选择、成本与库存门禁 | AutoFish 规则引擎 | 全量留痕 |
| 标题、描述和图片编辑指令 | Qwen，经 AutoFish 调用 | Pydantic 结构校验 |
| 文案事实复核 | 独立 Qwen 审核调用 + 确定性门禁 | 不合格自动改写 |
| 精品图片 | Qwen Image 2.0 参考图编辑 | 保留商品事实 |
| 图片结构、颜色、配件、文字和尺寸质检 | Qwen-VL + 程序 OCR 数值比较 | 不合格自动重画 |
| 商品更新、草稿生成、版本取代 | AutoFish | 数据库、审计日志和幂等记录 |
| 闲鱼网页登录、上传、选择、点击、验证码或异常 | Codex 或操作员 | 仅浏览器交接范围 |
| 闲鱼最终提交 | 未自动执行 | 等待可控网页操作 |

在没有企业身份和官方闲鱼写 API 的条件下，最后一段只能使用已登录的商家网页。系统不读取、导出或保存 Cookie，也不调用页面私有接口；这决定了 Codex/操作员仍需承担浏览器交接，而不是业务判断。

## 已实现链路

1. 从 `sourcing_candidates` 读取真实 1688 候选，检查详情核验、来源新鲜度、类目、供应商、图片、完整 SKU、价格、运费和库存。
2. 按证据、供应完整度、利润、库存和风险计算候选分；低于 70 分不进入后续流程。
3. Qwen 生成闲鱼标题、描述与参考图编辑指令。
4. 确定性文案门禁禁止代发、供应链、货源、批发、铺货、供应商名称、1688 新人价/包邮条件，以及图片生成和后台质检话术。
5. 独立 Qwen 文案审核逐项检查属性、功能、用途、质量、包装和承诺是否被来源事实支持。
6. 文案最多自动修正三次；仍不合格时，降级为仅由已核验来源标题、规格和类目组成的安全模板，不放宽事实门槛。
7. Qwen Image 2.0 使用真实来源图做参考图编辑；每个目标图片最多生成两次。
8. Qwen-VL 对比来源图与生成图，并逐字返回两图的可见文字。程序再次硬比较尺寸数字和单位，出现来源未核验尺寸即拒绝。
9. 仅通过质检的图片进入商品和草稿。被拒图片保留在审计资产中，但下载接口和发布草稿不暴露它们。
10. 生成 `REVIEW_READY` 草稿并停在 `READY_FOR_BROWSER_HANDOFF`。同一商品以前的待发布草稿自动标记为 `SUPERSEDED`。

4. 图片出现错误的 `1cm/2m` 尺寸且布尔质检漏过：增加可见文字回传和程序尺寸集合比较。

## 操作流程

1. 打开 AutoFish，进入“自主上架”。
2. 候选 ID 留空时由系统从合格候选中自主选择；需要定向复核时可输入候选 ID。
3. 选择必须通过质检的精品图数量，点击“由 AutoFish 自主生成”。
4. 在任务记录中查看候选评分、阶段状态、最终文案、合格图片和阻断原因。
5. 只有状态为“草稿已就绪”、图片质检达到要求、外部提交显示“未执行”的最新任务可以交给浏览器。
6. 浏览器交接只负责把草稿字段和合格图片填入已登录的闲鱼商家工作台。提交前仍需处理平台即时校验、验证码和账号风控。

## 仍然存在的边界

- 没有闲鱼官方写 API 时，不能把网页最终发布宣称为稳定的服务端全自动能力。
- 页面结构、验证码、账号风控和平台规则变化仍可能让浏览器交接转人工。
- 1688 新人价、包邮、库存和发货服务都具有时效性，实际采购前必须重新核价、核库存和确认下单资格。
- 图片模型和视觉模型不是事实来源；任何模型结论都必须经过程序门禁，失败时宁可阻断或降级为事实模板。
- 当前验收只证明“真实选品到闲鱼待发布草稿”的闭环，不代表支付、退款、投诉、平台介入等高风险动作可以无人监管。

## 安全说明

API Key、NAS 密码和后台密码没有写入本文档、源码、测试或审计明文。大模型密钥由系统加密保存，页面只返回脱敏提示。发布自动化保持 `REVIEW` 模式；自主生成任务不会调用闲鱼写入 Adapter，也不会点击网页最终提交。
