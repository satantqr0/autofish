## 3. 已实施的系统策略

AutoFish 已新增真实日指标表、官方 XLSX 导入、浏览器桥接只读自动采集、1/7/30 天流量面板、商品分层诊断和审计日志。系统使用以下硬门槛，避免大模型凭感觉频繁修改：

| 诊断 | 判定门槛 | 动作 |
|---|---|---|
| 等待 T+1 | 新商品尚无官方日报 | 保持首图、标题、价格；次日采集 |
| 数据采集中 | 少于 3 个完整日，或累计曝光少于 60 | 不改价；采满门槛 |
| 曝光不足 | 上架至少 3 天且累计曝光少于 30 | 检查类目、搜索词覆盖、账号垂直度和发布时间 |
| 点击率偏低 | 至少 3 天、曝光至少 60、点击率低于 2% | 先换首图且保持原价；标题前 20 字突出品类与规格；单变量观察 72 小时 |
| 浏览后意向偏低 | 浏览至少 20、询单率低于 3% | 补尺寸、材质、场景和履约事实；再检查同类价格 |
| 询单未成交 | 询单至少 3、支付为 0 | 优化首响、库存/运费/时效话术和议价底线 |
| 退款风险 | 支付至少 3 单且成功退款率至少 10% | 停止放量和自动调价，人工核对质量与描述一致性 |
| 表现健康 | 点击率至少 5%或已有支付 | 保持素材，复制有效结构，不频繁改动 |

价格调整额外要求至少 7 天证据，且始终受最低售价与最低利润保护。系统不会用降价掩盖首图或标题问题。

## 4. 当前调整节奏

1. `2026-08-18`：已完成商品精品净图和尺寸图整改，锁定为新素材基线；当天新商品等待 T+1。
2. `2026-08-19` 至 `2026-08-21`：每天采集近 1 天官方数据，不同时修改首图、标题和价格。
3. `2026-08-22`：首次按 3 个完整日、60 次曝光门槛分层。
4. 对满足低点击条件的商品：第一轮只更换首图；保持标题和价格，观察 72 小时。
5. 若首图实验后点击率仍低于 2%：第二轮只调整标题前 20 字和类目关键词，再观察 72 小时。
6. 只有点击率达到可接受水平且累计浏览至少 20，才评估详情、信任信息和价格。

本期不直接修改线上商品，原因是 2026-08-18 才完成精品图整改，官方数据尚未回传；此时再次改图或改价会破坏基线，无法判断整改是否有效。

## 5. 每日无人值守流程

1. 每天 10:00 后，调度器以 `browser:auto:metrics:YYYY-MM-DD` 幂等键创建一次只读采集任务。
2. Chrome 桥接固定打开闲鱼「商品数据」并选择「近1天」，核验结束日期等于昨天。
3. 最多逐页读取 500 款商品的 16 项经营指标；不读取 Cookie、买家信息、页面网络响应或截图。
4. 后端校验商品 ID、非负数、浏览不大于曝光、日期一致性后按“账号 + 商品 ID + 日期”幂等写入。
5. AutoFish 流量诊断页自动重算 1/7/30 天漏斗与商品分层。
6. 登录失效、验证码、风控提示、日期不符或表格结构变化时停止并转人工；不会尝试绕过。

浏览器扩展已更新并重新加载到 `0.4.0`，之后每日采集不再依赖 Codex。若浏览器未常开，可在 AutoFish「流量诊断」页手工上传官方 XLSX，结果与自动采集使用同一套数据库和诊断规则。
