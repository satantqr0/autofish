# AutoFish 商业交付标准

## 产品定义

AutoFish 商业版只提供客户自有设备上的单租户私有部署。客户本人拥有并登录闲鱼账号，客户本人决定商品、价格、发布和履约，并承担经营主体、税务、消费者保障和平台规则责任。

服务方可以提供安装、初始化、版本更新、故障诊断和系统使用培训，但不得接管客户账号、保存客户密码/Cookie/验证码/支付凭证、代替客户处理支付退款或绕过平台风控。

## 交付前门禁

1. 客户确认设备、网络、备份空间和常驻 Chrome 可用；
2. 客户确认闲鱼账号归本人或经营主体合法控制；
3. 客户确认货源、图片、品牌和商品描述具备合法使用依据；
4. 客户阅读并确认当前版本商业条款、隐私和合规边界；
5. 经营性销售所需登记、税务、消费者保障由客户自行确认；
6. 不接受多账号群控、刷量、侵权、虚假来源、验证码绕过和收益保证需求。

## 标准交付 SOP

1. 在客户自有设备部署 Docker Compose，不开放 PostgreSQL/Redis 公网端口；
2. 生成独立管理员密码、JWT、加密密钥和浏览器桥接令牌；
3. 配置 HTTPS 或限制为可信局域网访问；
4. 客户本人在本地 Chrome 登录闲鱼卖家工作台并加载桥接扩展；
5. 客户自行保存模型 API Key，服务方不留存明文；
6. 执行迁移、健康检查、备份和恢复清单验证；
7. 使用一款低风险商品完成预填或 REVIEW 金丝雀；
8. 验证限额、幂等、Kill Switch、验证码停手和结果不明确不重试；
9. 导出验收报告并由客户在商业化控制台确认边界；
10. 记录交付总工时，不记录客户账号凭证。

## 验收结果

交付成功仅表示软件安装、权限门禁、备份、浏览器桥接和指定测试流程可用，不表示平台授予第三方 API 权限，也不表示客户一定获得曝光、询单、订单、收入或利润。

正式商业版的内部门槛：3 个独立付费客户、最近一期 30 天留存不低于 67%、单客交付不超过 4 小时、每活跃客户每月支持不超过 0.5 小时。

## 支持边界

- 包含：AutoFish 自身缺陷、配置说明、版本更新、备份恢复指导；
- 不包含：平台封禁、账号申诉、商品侵权纠纷、买家售后、税务申报、硬件故障、第三方模型欠费、网络服务异常；
- 平台页面改版导致桥接失效时先关闭相关自动能力，经单款验证后恢复；
- 风控、验证码、人脸或二次确认由客户本人在官方页面处理。
