# 平台与业务合规

AutoFish 仅供用户管理自己的单个闲鱼账号和合法供应链业务。技术可执行不代表平台允许；启用任何真实 Adapter 前，用户需确认当时有效的闲鱼、淘宝/1688 规则、供应商授权、消费者权益、税务、广告与知识产权义务。

## 强制禁止

- 验证码/滑块绕过、人脸或二次验证自动化；
- 设备指纹伪造、反检测、IP 池规避、批量养号和封号规避；
- 虚假交易、刷单、刷评价、刷曝光/收藏/想要；
- 假物流、假货、侵权商品、虚构商品来源或“自用闲置”经历；
- 未经授权收集、转售或训练使用买家/平台数据；
- 将系统包装为集中托管第三方账号、登录态或买家数据的商业 SaaS；合规商业交付仅允许客户自有设备上的单租户私有部署，且客户本人掌握账号、数据与最终经营责任。

## 商品真实性

商品页面必须如实说明商品性质、规格、材质、兼容性、发货时间、售后规则和供应方式。AI 不得生成“老婆买多”“朋友送”“公司福利”“拆机”“自用闲置”等无事实来源描述。

第一阶段排除服装鞋靴、食品、化妆品、手机、显卡、主板、SSD、内存、电池、充电宝、易碎屏幕、高售后电子模块、来源不明品牌和疑似侵权商品。

## 人工接管

出现以下任一事件立即停止自动流程：验证码、人脸、二次确认、风险提示、退款/退货、投诉、平台介入、赔偿/法律问题、兼容性无法确认、异常金额/地址/付款、供应商责任争议。

## 外部项目

- `goofish-cli` 虽为 Apache-2.0，但其私有平台接口仍受平台规则约束；只以独立 Adapter 使用并保留 NOTICE。
- `1688-shopkeeper` 无许可证，不复制、修改、再分发代码；启用前确认 AK/API 授权。
- `xianyu-auto-reply` 为 AGPL-3.0 且 README 另有限制，只研究架构；不复制、不链接、不部署。
- `XianyuAutoAgent` 为 GPL-3.0，只研究思想；不复制、不链接。

## 上线门槛

真实平台写操作必须经过：规则复核、用户登录授权、限流、Kill Switch 演练、失败人工接管、数据备份、测试账号小流量验证和 14 天稳定性记录。默认保持关闭。
