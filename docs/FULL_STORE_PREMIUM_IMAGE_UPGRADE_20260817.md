## 三、图片策略

1. 主图统一采用 1:1 高分辨率电商构图，增强主体分离、光影层次、材质质感和画面秩序。
2. 不改变商品数量、型号、包装、标签、序列号、配件范围或使用痕迹。
3. 涉及故障、缺件、单机和掉漆的商品，在主图中保留或直接标出关键信息。
4. 每件商品的新精品图排在第一张，原始图片继续作为成色和细节证据。
5. 未通过图片美化制造“全新”“无瑕疵”“配件齐全”等与实物不符的印象。
