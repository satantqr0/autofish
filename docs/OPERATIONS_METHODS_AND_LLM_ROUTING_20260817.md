# AutoFish 运营方法中心与大模型路由评估

> 版本：2026.08.17-1  
> 官方价格核验日期：2026-08-17  
> 系统入口：`/operations`  
> 数据接口：`GET /api/v1/operations/guide`

## 1. 本次落地结果

运营方法不再只存在于分散文档中。系统内新增“运营方法”页面，统一展示：

- 14 项端到端运营流程；
- 每项流程的触发条件、开始前门禁、标准步骤、必须证据、停手条件和验收标准；
- 5 个大模型 API 的能力与官方价格快照；
- 可编辑的月度 token 成本测算器；
- 单厂商、最低成本、国内链路三套生产路由；
- 成本控制规则和模型上线门禁。

这个入口只提供方法、事实和预算控制，不会自动配置 API Key、启用平台写入或改变自动化开关。

## 2. 全链路方法目录

| 序号 | 流程 | 系统入口 | 自动化边界 | 核心完成条件 |
|---:|---|---|---|---|
| 01 | 货源发现与初筛 | 选品中心 | 受控自动 | 来源、SKU、价格和评分均可追溯 |
| 02 | 供应事实核验 | 1688 能力台 | 人机协同 | 库存、运费、交期和售后有真实证据 |
| 03 | 商品建档与定价 | 商品中心 | 受控自动 | 价格底线和利润公式可解释 |
| 04 | 精品图片制作与质检 | 闲鱼商品 | 人机协同 | 图片真实、清晰、无虚构和侵权 |
| 05 | 货主口吻文案与禁词检查 | 草稿管线 | 受控自动 | 无代发暗示，事实与图片一致 |
| 06 | 闲鱼发布、确认与回填 | 闲鱼工作台 | 受控写入 | 平台真实可见，ID/URL 已回填且幂等 |
| 07 | 问价、咨询与 AI 回复 | AI 客服 | 受控自动 | 回复有事实依据，越界立即转人工 |
| 08 | 订单识别与事实同步 | 订单 | 只读自动 | 平台状态一致，未付款订单不采购 |
| 09 | 采购预览与供应商下单 | 采购任务 | 人工确认 | SKU、金额、库存和地址再次核验 |
| 10 | 物流单号核验与发货同步 | 物流 | 受控写入 | 真实运单一一对应，不虚假发货 |
| 11 | 售后、退款与纠纷接管 | 风险与人工 | 人工接管 | 证据时间线完整，由操作员最终决定 |
| 12 | 日常巡检、异常与人工任务 | 任务中心 | 受控自动 | 异常有状态、证据和恢复审计 |
| 13 | 对抗性测试与上线门禁 | 系统设置 | 人工验收 | 幂等、熔断、底线和急停全部通过 |
| 14 | NAS 部署、备份与恢复 | 系统设置 | 受控运维 | 服务健康、备份有效、版本可回退 |

每项流程的完整步骤存放于 `backend/app/services/operations_catalog.py`，由接口返回到管理后台。前后端共用同一版本号，避免页面和文档分别维护导致口径漂移。

## 3. 评估结论

### 3.1 若只选一个厂商

推荐使用 **GPT-5.6 Luna + GPT Image 2**。

理由：

- GPT-5.6 Luna 同时覆盖中文文本、图片输入、结构化输出、函数调用和长上下文；
- GPT Image 2 补齐精品主图、场景图和图片编辑；
- 同一厂商减少鉴权、账单、SDK、故障切换和数据结构的维护成本；
- Luna 标准文本价格为每百万 token 输入 **$0.20**、输出 **$1.20**，在本次比较中已经属于低价模型；
- 仍需在 NAS 上验证官方 API 的网络、账户、付款与持续可用性。

官方来源：[OpenAI 模型目录](https://developers.openai.com/api/docs/models)、[OpenAI API 价格](https://developers.openai.com/api/docs/pricing)。

### 3.2 若以最低综合成本为第一目标

采用三层路由：

1. 在线客服、视觉理解、图片事实质检：GPT-5.6 Luna；
2. 可延迟的批量分类、摘要和文案：DeepSeek V4 Flash 低谷时段；
3. 精品图片生成：GPT Image 2，仅在上新或重做素材时调用。

DeepSeek V4 Flash 官方快照的高峰价为每百万 token 输入 **$0.44**、输出 **$1.32**；低谷价为 **$0.22 / $0.66**。它支持 JSON、工具调用和多种 API 格式，但官方定价与能力页没有提供覆盖本项目所需的图片输入和图像生成能力，因此不能单独完成 AutoFish 全部任务。

官方来源：[DeepSeek API 价格](https://api-docs.deepseek.com/quick_start/pricing/)。

### 3.3 国内网络与人民币结算优先

备选为 **Qwen3.7 Plus + 阿里云同厂商图像模型**。

本次采用中国内地、输入不超过 256K 档位的公开标价快照：每百万 token 输入 **¥2**、输出 **¥8**。它在中文、视觉、工具和国内账户链路方面匹配度高，但必须先用 AutoFish 固定测试集验证 JSON 一次通过率、视觉事实一致性和客服质量。

官方来源：[阿里云百炼模型价格](https://help.aliyun.com/en/model-studio/model-pricing)、[模型与工具文档](https://help.aliyun.com/zh/model-studio/models)。

## 4. 标准文本成本对比

参考场景：每月输入 1,200 万 token、输出 240 万 token；美元换算仅按预算参考汇率 7.20，未计图片、税费、搜索工具、网络和第三方渠道加价。

| 模型 | 官方标准价（输入 / 输出） | 月度文本预算约 |
|---|---:|---:|
| GPT-5.6 Luna | $0.20 / $1.20 | ¥38.02 |
| Qwen3.7 Plus | ¥2.00 / ¥8.00 | ¥43.20 |
| Gemini 3.1 Flash-Lite Preview | $0.25 / $1.50 | ¥47.52 |
| DeepSeek V4 Flash（高峰） | $0.44 / $1.32 | ¥60.83 |
| DeepSeek V4 Flash（低谷） | $0.22 / $0.66 | ¥30.41 |
| Claude Haiku 4.5 | $1.00 / $5.00 | ¥172.80 |

Google 与 Anthropic 官方来源：[Gemini API 价格](https://ai.google.dev/gemini-api/docs/pricing)、[Gemini 3 模型说明](https://ai.google.dev/gemini-api/docs/gemini-3)、[Claude API 价格](https://platform.claude.com/docs/en/about-claude/pricing)。

这些数值只是文本预算快照。图片生成的成本与分辨率、质量、输入图和图像 token 直接相关，必须在真实素材样本上单独核算，不能把文本单价外推到图片。

## 5. 生产路由边界

| 任务 | 主路由 | 备选/降级 |
|---|---|---|
| 意图分类、字段抽取、普通问答 | GPT-5.6 Luna | DeepSeek V4 Flash 低谷批处理 |
| 商品图识别、生成图事实质检 | GPT-5.6 Luna | Qwen3.7 Plus Vision |
| 标题、详情、客服回复草稿 | GPT-5.6 Luna | DeepSeek V4 Flash |
| 精品主图和场景图生成 | GPT Image 2 | 国内图像模型 + 人工验收 |
| 退款、纠纷、价格越界、事实冲突 | 人工接管 | AI 只生成事实摘要 |

大模型只能提供结构化建议。价格底线、禁词、权限、幂等、频率限制、熔断、自动化状态和最终人工接管仍由确定性代码控制。

## 6. 节省开支的实施顺序

1. 所有输出先使用 JSON Schema，限制字段和最大长度；校验失败只自动重试一次。
2. 固定系统规则、商品事实与常用说明使用提示缓存；会话只传最近必要消息和结构化摘要。
3. 可延迟任务走 Batch/Flex 或 DeepSeek 低谷时段，不为离线任务支付实时成本。
4. 图片先用视觉模型做低成本质检，只有异常样本进入人工；图片生成按商品调用，不按会话调用。
5. 每次请求记录 provider、model、任务、输入/输出 token、缓存命中、耗时、结果和成本。
6. 每周按“每千任务成本、Schema 一次通过率、事实错误率、人工接管率、P95 延迟”复盘路由。

## 7. 模型上线门禁

- 建立至少 200 条固定样本，覆盖中文客服、商品事实、禁词、价格底线、图片一致性、恶意输入和提示词攻击；
- Schema 一次通过率目标不低于 99%；
- 商品事实幻觉率必须为 0；
- 退款、纠纷、支付、价格越界和来源冲突不得由模型自动决定；
- 新模型先影子运行 7 天，比较质量、P95 延迟、成本和人工接管率，再切换生产流量；
- 价格或模型版本变化时更新 `price_checked_at`，重新跑固定评测集。

## 8. 安全说明

本评估没有把任何 API Key 写入源码、页面或文档。后续真正接入模型时，凭据只能通过 NAS 上的只读凭据文件或部署环境注入，并应独立设置月度预算、请求限额和紧急停止开关。
