# AutoFish 私有部署隐私说明草案

> 草案状态：待律师审核。AutoFish 默认采用客户自有单租户部署，本说明不授权集中收集平台或买家数据。

## 数据控制关系

客户是其经营数据和买家个人信息的责任主体。AutoFish 软件运行在客户自有设备，服务方默认无法访问数据库、闲鱼登录态或模型密钥。

## 本地处理的数据

- 商品、SKU、供应商、成本、价格、库存和素材事实；
- 闲鱼商品 ID、状态及客户经授权取得的经营指标；
- 经授权取得的订单、会话和物流必要字段；
- 自动化任务、AI 决策、异常、审计和备份记录；
- 商业化控制台中的线索、演示、付费、收入、留存和工时汇总数据。

商业化控制台不得录入潜在客户姓名、手机号、闲鱼账号、密码、Cookie、Token、验证码、支付凭证或买家信息。

## 不处理或不集中收集的数据

服务方不托管闲鱼密码、Cookie、验证码、人脸信息、支付凭证，不出售平台或买家数据，不使用客户数据训练公共模型。浏览器扩展不向服务方上传登录态。

## 第三方模型

客户启用模型 API 时，应使用自己的密钥并了解对应模型服务商的数据政策。AutoFish 只发送完成任务所需的最小事实；买家地址、支付信息和无关聊天内容不得进入模型输入。

## 保存、备份与删除

客户决定本地数据和备份的保存期限。终止服务时客户可停止容器、导出数据库并删除部署目录和备份。删除前应核对法律、税务、交易和争议处理所需的法定留存义务。

## 远程支持

远程支持应由客户临时授权并全程可见。提交日志前必须脱敏；支持结束后关闭临时账号、端口和远程访问。服务方不得复制完整数据库作为普通工单附件。

## 安全事件

发现凭证泄露、异常登录、未授权数据访问或备份暴露时，应立即停止自动化、轮换凭证、隔离访问、保留审计证据，并由责任主体依据适用法律评估通知义务。
