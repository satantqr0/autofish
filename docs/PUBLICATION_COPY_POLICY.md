# 闲鱼发布文案中性卖家口吻门禁

AutoFish 的闲鱼发布文案统一使用自然、中性的商品介绍口吻。供应商页面中的招商、铺货、代发和分销话术，以及“本人发货”“本人负责销售”“发货安排”等卖家身份或履约自述，不得进入闲鱼标题或商品描述。

## 生成规则

- 草稿生成时自动清除“一键代发”“支持代发货”“一件发货”“一件代发”“代发”“厂家直发”“供应商直发”“供应商”“供应链”“货源”“铺货”“分销”“无需囤货”“招代理”等同类话术。
- “代发包邮”只保留可由实际运费事实支持的“包邮”表达，不保留代发信息。
- 商品描述统一追加：`下单前请先确认库存和规格，商品细节及售后问题可随时沟通。`
- 不写“自用闲置”“购于某处”等虚假来源，也不在没有事实依据时声称商品已在手或全新未拆。

## 最终发布门禁

草稿生成后，以下入口都会重新校验标题和描述：

1. 平台发布动作预检。
2. 平台发布动作实际执行前复检。
3. 闲鱼卖家工作台浏览器预填任务创建。
4. 浏览器代理领取任务前复检。

任何入口发现代发/供应链话术、本人发货等身份自述，或未检测到统一的中性库存与售后提示，都会阻止发布。旧草稿必须重新生成或修正文案后才能继续。

## 文案示例

推荐：

> 下单前请先确认库存和规格，商品细节及售后问题可随时沟通。

禁止：

> 支持一件代发、一键铺货、厂家直发，无需囤货。
