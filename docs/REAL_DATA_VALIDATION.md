## 已确认的外部能力边界

- [官方闲鱼开放平台快速开始](https://open.goofish.com/doc/quick-start.html)显示平台为邀请准入；创建应用和获取 AppKey 需要企业相关条件，订单类能力还要求对应 B 端应用密钥与权限审批。因此“有闲鱼账号”不等于“已获得接口权限”。
- [官方闲鱼 API 目录](https://open.goofish.com/doc/api/basic/showToast.html)是最终能力依据；AutoFish 不把第三方 CLI 的私有能力描述成官方 API。
- `goofish-cli` 参考版本可提供账号、商品、会话和历史消息只读输出，但订单仍在其路线图中，AutoFish 对其订单方法返回 `UNSUPPORTED`。
- `1688-shopkeeper` 参考版本需要 1688 AI 版 AK，可输出搜索结果和 Markdown 型详情；它没有可依赖的稳定结构化库存/采购/物流契约，AutoFish 不解析猜测为实时库存。
- 1688 社区官方 `1688-product-find` 公开声明的搜索结果含 SKU、库存、供应商、起批量、服务和卖点字段；AutoFish 已实现候选兼容映射，但未安装或运行该社区包。待包体与埋点审计、20 条真实字段对照完成前，不切换生产 Adapter。
- Adapter 健康检查必须执行真实签名的只读 `shops` 请求；参考 CLI 的 `check` 只校验 AK 格式，不能作为已授权证据。
- 兼容 CLI 只作为隔离的只读验证方式；推荐生产接入仍是经授权的 JSON Gateway。
- 实际启用前还需由账号所有者复核[闲鱼社区软件服务许可协议](https://terms.alicdn.com/legal-agreement/terms/suit_bu1_other/suit_bu1_other201708081618_51146.html)和[1688 平台相关服务协议](https://terms.alicdn.com/legal-agreement/terms/common_platform_service/20260127150801893/20260127150801893.html)。

## 字段验证清单

供应商品：外部商品 ID、标题、类目、供应商 ID/名称、来源 URL、图片、每个 SKU 的外部 ID/规格、币种、采购价、运费、库存、抓取时间、来源版本、原始载荷 hash。

闲鱼：外部账号 ID、昵称、账号状态、商品 ID/标题/价格/状态、会话 ID、客户 ID、消息 ID/方向/类型/正文/时间、订单 ID/状态/成交额/预计利润/实际利润、来源版本、抓取时间。

## 不匹配处理

- 缺稳定外部 ID：整个对象拒绝进入事实库。
- 缺 SKU、类目或供应商标识：候选可展示但 `import_ready=false`。
- 命中排除类目：状态为 `EXCLUDED`，API 与页面均禁止导入。
- 价格/库存只有展示文本：保留原始快照，结构化字段留空。
- 订单能力不存在：页面显示“当前 Adapter 不支持”，不是空订单成功。
- 出现验证码、人脸、二次确认、风控提示：标记 `MANUAL_REQUIRED`，由操作员转官方界面处理。

## 获得凭证后的验收步骤

1. 在独立凭证目录或 Gateway Secret Store 配置凭证，不写入项目文件。
2. 先只调用 `/health`，确认 `authenticated=true`、读写声明和能力矩阵；首次仍以只读方式接入。
3. 在隔离测试账号读取少量数据，与官方页面逐条对照。
4. 连续重放同一批数据，确认快照幂等、业务行不重复、审计和 correlation ID 完整。
5. 模拟超时、429、凭证过期和未知结构，确认不会自动转成写操作或无限重试。
6. 完成只读验收后才设置 `AUTOFISH_ADAPTERS_ENABLED=true`；写总开关继续保持 `false`。
7. 写入另做 `REVIEW + 每日上限 1` 的逐动作金丝雀，验证平台结果、幂等、熔断、审计与 Kill Switch 后才考虑自动模式。
