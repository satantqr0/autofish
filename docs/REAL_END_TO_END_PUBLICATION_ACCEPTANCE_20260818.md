## 运行状态回写修复

实操发现：人工浏览器已经成功发布时，原有回填只会更新闲鱼商品和草稿，仍可能让浏览器任务停在 `QUEUED`、自主运行停在浏览器交接阶段。

现已增强 `POST /api/v1/xianyu/manual-publications`：

1. 核验外部商品为 `ACTIVE` 且属于目标草稿。
2. 找到该草稿最新的 `BROWSER_PUBLISH_PRODUCT` 任务。
3. 写入 `submission_attempted=true`、成功证据、闲鱼商品 ID 和公开链接。
4. 把浏览器任务更新为 `SUCCEEDED / SUBMITTED`。
5. 把草稿更新为 `PUBLISHED`。
6. 把自主运行更新为 `PUBLISHED / XIANYU_PUBLISHED`。
7. 清除租约和旧错误，重置发布熔断计数，并写入独立审计日志。
8. 重放相同结果不会重复创建闲鱼商品或重复迁移终态。
