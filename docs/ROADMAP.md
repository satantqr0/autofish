# Phase 0–10 路线图

## Phase 0：基础工程

交付：Compose（frontend/backend/worker/postgres/redis）、FastAPI、Next.js、Celery、Alembic、登录、健康/就绪检查、结构化日志、审计、全局/分项 Kill Switch、CI 级测试命令。

门禁：全栈可启动；数据库 migration 可从空库运行；无默认弱密码；PostgreSQL/Redis 不暴露；真实 Adapter 全关闭。

## Phase 1：商品中心

交付：Supplier、SupplierProduct、SupplierSKU、Product、ProductSKU、来源映射、价格/库存历史、人工新增和批量导入、原始快照 hash。

门禁：10 SKU 数据可追溯；重复导入幂等；排除类目会被拦截或人工审核；列表、筛选、详情和历史可用。

## Phase 2：利润与评分

交付：Decimal PricingEngine、PricingRule、最低/建议售价、预计/实际利润结构、八维 ProductScore、总览、风险队列和审计。

门禁：资金测试 100% 通过；任何建议价不得低于最低价；评分可解释并版本化；Kill Switch UI/API 生效。

## Phase 3：1688 只读 Adapter

状态：产品代码完成，真实授权待配置。

已交付 `json_gateway` 与隔离的 `shopkeeper_cli` 两种生产只读实现、搜索/详情/SKU 契约、同步批次、脱敏快照、候选池、Canonical Feed、八维评分输入、排除类目和商品中心导入。另已加入官方社区 `1688-product-find` 的候选兼容层，支持公开 JSON 中的 SKU/库存/供应商字段，但运行时尚未审计和启用。结构化实时库存/运费缺失时保持 `UNSUPPORTED`，不猜测。

门禁：经授权的 Gateway 或 1688 AI AK；至少 20 条真实商品完成字段对照；库存/价格过期策略确认；社区包体版本、哈希、许可证、网络目标和埋点完成审计；API 授权未确认时不得启用。

## Phase 4：闲鱼只读优先 Adapter

状态：产品代码完成，官方准入/真实授权待配置。

已交付 `json_gateway` 与隔离的 `goofish_cli` 两种只读实现、账号/商品/会话/消息同步、订单能力探测、快照幂等、只读控制台和人工接管字段。订单/发货能力缺失时返回 `UNSUPPORTED`，不自行补私有协议。

门禁：官方邀请准入、企业应用/应用密钥和已审批权限，或用户自有且合规的只读 Gateway；至少一个真实账号完成字段对照；所有写方法继续关闭。

## Phase 4.5：ClawHub 八大能力台

状态：`0.9.0` 已交付安全闭环。

已交付关键词找货、趋势/商机、图片/链接 Adapter 契约、候选对比、供应商事实池、统一动作预检、S/A/B/C 评估、商品诊断、闲鱼待审草稿和询价人工任务。Product Find 外部运行时和询价自动发送尚未启用；所有外部写执行固定阻断。

门禁：Product Find 包体、依赖、许可证、网络目标和遥测通过审计后才可启用图片/链接找货；询价自动发送、闲鱼发布或采购必须取得官方权限、加入限额/人工确认，并通过真实小流量验收。

## Phase 5：AI 客服建议

状态：代码完成，真实消息授权与金丝雀待完成。已实现确定性 Router/Customer/Pricing、结构化 AI decision、建议去重、事实型低风险回复与确认发送；退款、投诉、售后、赔偿、法律、未知意图和兼容性不明直接人工。

## Phase 6：发布

状态：代码完成，官方业务权限/媒体链路与金丝雀待完成。已实现待审草稿、发布/改价/下架、幂等写入、每日限额、最小间隔、熔断、前后审计和结果不确定时停止重试。

## Phase 7：订单

状态：核心模型、规范化 webhook、订单轮询和异常状态人工接管已完成；真实官方订单事件权限、订单项完整字段和隐私密钥托管待验收。

## Phase 8：采购

状态：人工任务与自动调度入口完成，外部交易仍强制人工。自动采购/支付等待 1688 官方交易权限、库存/当前价/最低利润三重校验和支付确认方案；不实现网页 RPA。

## Phase 9：物流

状态：物流策略范围、订单事件、回填动作状态机和 Gateway/TOP 契约完成；真实物流单号引用、供应商物流源和小流量回填待验收。

## Phase 10：无人值守

连续 14 天通过：服务稳定、无重复发布、价格代码校验 100%、AI 不突破最低价、每条 AI 回复有上下文、异常可接管、所有动作可审计，再按发布/客服/采购/调价逐项启用。

当前 `0.9.0` 已完成 Phase 0–9 的代码底座，并把可授权写动作接入统一安全状态机；生产环境的实际模式以运行就绪页和各项硬开关为准。Phase 10 仍取决于闲鱼/1688 授权能力、真实订单字段、金丝雀及连续 14 天稳定性证据，不能仅凭代码测试宣称“已无人值守”。
