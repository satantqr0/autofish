# 1688 候选人工核验补全

## 用途

当授权只读 Adapter 只能返回商品 ID、标题或价格带，无法返回结构化 SKU、供应商标识、库存、运费和图片时，操作员可在“1688 选品”页面使用“人工核验补全”。该流程只补充供应事实，不调用采购、支付或平台发布接口。

## 操作流程

1. 在候选详情中打开“查看授权来源”，确认当前页面是该候选的 1688 商品详情页。
2. 点击“人工核验补全”。
3. 从当前详情页逐项抄录类目、供应商 ID/名称和阿里 CDN 主图地址。
4. 为每个准备经营的 SKU 填写真实 SKU ID、规格 JSON、采购价、单件运费和可售库存。
5. 提交后，系统生成去敏事实快照、同步批次和审计记录；只有字段完整且未命中排除类目时，候选才显示“可导入”。

API：`POST /api/v1/sourcing/{candidate_id}/manual-verification`

## 校验门禁

- 来源必须是 `https://detail.1688.com/offer/{商品ID}.html`，且链接 ID 必须与候选 ID 完全一致。
- 商品图片必须是阿里 CDN 的 HTTPS 地址，不接受任意站点、内网地址或带认证信息的 URL。
- `captured_at` 必须包含时区，不能来自未来，证据时效不超过 24 小时。
- 至少一个 SKU；SKU ID 不得重复；价格、运费和库存必须在允许范围内。
- 请求拒绝未知字段，因此 Cookie、Token 等额外字段不能混入证据。
- 已排除和已导入候选不能覆盖供应证据。
- 完全相同的证据重放复用同一快照，不重复制造事实记录；每次操作仍保留独立同步批次和审计痕迹。

## 数据边界

人工核验是“操作员从已获准页面确认并录入事实”，不是平台 API 的替代品。它不能证明未来库存、价格或运费不变，也不会自动下载图片、创建采购单、付款或发布闲鱼商品。导入商品中心后，发布前仍需执行最新价格/库存复核、定价底线校验、图片处理和平台结果复核。

## 回归测试

覆盖完整补全、幂等重放、来源 ID 不一致、非 HTTPS 来源、非阿里 CDN 图片、过期证据、重复 SKU、未知敏感字段以及终态候选覆盖保护。
