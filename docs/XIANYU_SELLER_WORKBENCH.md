# 闲鱼专业卖家工作台接入核验

核验日期：2026-08-16  
入口：`https://seller.goofish.com`

## 已确认的账号能力

账号可正常进入“专业卖家工作台”。页面提供：

- 数据总览、商品数据、粉丝数据、客服数据；
- 商品发布、商品管理、运费模板；
- 订单、退款、评价、投诉和退货地址管理；
- 子账号、客服分流与安全中心；
- 收入/支出账单、发票和推广；
- 商品数据报表下载入口。

商品数据报表可见字段包括商品 ID、价格、曝光次数/人数、浏览次数/人数、询单人数、支付人数/订单数/金额、浏览支付转化率，以及发起/成功退款人数、订单数和金额。这些字段可用于 AutoFish 的真实经营分析、商品诊断和上架后评估。

## 接入决策

专业卖家工作台是官方运营页面，但页面登录态本身不等于开放 API 授权。AutoFish 不读取或复用浏览器 Cookie，不调用逆向得出的私有接口，不在 NAS 中模拟登录。

优先级如下：

1. 官方报表下载后，通过严格 CSV/XLSX Schema 导入 AutoFish；
2. 取得闲鱼邀请准入、B 端 AppKey、获批权限与卖家授权后，通过 TOP/消息服务接入；
3. 若由自建 Gateway 对接，必须使用官方授权、幂等写入和规范化 webhook；
4. 本地浏览器桥接保留登录态在 Chrome，并可在硬开关与 PUBLISH 策略放行后完成图片上传、字段回读、最终提交和结果回写；验证码、登录失效、风控与结果不明确仍转人工。

## 已实现的浏览器桥接

`browser-bridge/` Chrome 扩展和 `/api/v1/xianyu/browser-bridge` 控制面已投入使用；`0.4.0` 新增商品经营日报只读采集：

- 通过独立桥接令牌连接 NAS，不复用后台登录 Cookie；
- 扩展每 30 秒发送心跳并领取一个带 300 秒租约的任务；
- 只接受 `OPEN_MODULE`、`CAPTURE_OVERVIEW`、`CAPTURE_PRODUCT_METRICS`、`PREFILL_PRODUCT`、`PUBLISH_PRODUCT` 五种白名单操作；
- 经营日报采集固定打开「商品数据」和「近1天」，逐页回传 16 项结构化经营指标；日期不符、风控或结构变化时停止；
- 预填任务的标题、描述、价格、类目和图片清单由服务端根据已校验草稿生成，不接受任意脚本或 CSS 选择器；
- 扩展 0.3.0 支持预填和受控发布；发布图片必须来自自主流水线并通过视觉 QA 与 SHA-256 完整性校验；当菜单被页面浮层遮挡时，仅允许跳转到固定同源商品发布路由；最终按钮通过短时、受限的调试通道发送一次可信鼠标事件并立即脱离；
- 发布提交前重新读取文案与价格并等待页面智能属性识别；发布按钮不可用时不尝试绕过；
- 进入 `SUBMITTING` 后发生断线不会重试，避免重复商品；
- 不读取或上传 Cookie、Token、密码、浏览器存储、完整页面文本、截图和买家隐私；
- 出现验证码、滑块、安全验证或结构变化时立即返回 `MANUAL_REQUIRED`；
- 租约超时最多重试三次，之后创建人工任务并停止。

控制台入口为 `/xianyu-workbench`。它展示代理在线状态、模块入口、可用草稿和任务审计，不使用 `iframe` 或反向代理嵌入闲鱼页面。

## 官方能力与限制

官方文档披露订单查询、物流发货、关闭订单、退款查询及订单/退款状态消息等能力；这些能力需要申请对应权限，并使用卖家授权 token。官方还要求用户 ID、订单和隐私数据按其安全规则部署/存储，不能因为工作台页面可见就直接同步到 NAS。

当前代码已将物流发货方法校正为官方文档中的 `alibaba.idle.isv.order.ship`。真实启用仍需 B 端应用权限、业务标识、卖家授权、物流字段和数据存储合规方案。
